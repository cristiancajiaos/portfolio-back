# Instrucciones para ejecutar

1. Iniciar el contenedor de Docker
```
docker-compose up -d
```
2. Ejecutar la aplicación
```
npm start run:dev
```
3. Ejecutar el seed
```
http://localhost:3000/api/seed
```
